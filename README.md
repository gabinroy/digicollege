# DigiCollege 🎓

*A Flutter-based UI project to digitize college experiences.*

## 📌 Overview

DigiCollege is a **Flutter UI build** designed to simulate a digital college environment.
It provides a seamless interface for students to **log in, access the dashboard, and view/play course videos.**

This project is focused on **UI/UX design** and can be extended with backend integrations later.

🔗 **Live Demo:** [DigiCollege](https://digicollege.curionative.com)

---

## 🚀 Features

* 🔐 **Login Page** – Simple authentication UI
* 📊 **Dashboard** – Clean layout for quick access to courses
* 🎥 **Video Page** – UI for lecture video playback
* 🎨 **Modern UI** – Built with Flutter’s flexible widget system

---

## 🛠️ Tech Stack

* **Framework:** Flutter
* **Language:** Dart
* **UI Toolkit:** Material Design

## ⚡ Getting Started

### 1️⃣ Clone the repo

```bash
git clone https://github.com/gabinroy/digicollege.git
cd digicollege
```

### 2️⃣ Install dependencies

```bash
flutter pub get
```

### 3️⃣ Run the app

```bash
flutter run
```
